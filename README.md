# About the project

This is a completely free quality-of-life modification pack for the Windows PC version of **Star Trek Fleet Command**.

All plugins are built on **BepInEx 6 IL2CPP** — an actively developed and maintained Unity plugin framework.

The pack is designed to make everyday gameplay more comfortable: automate routine mining and repairs, reduce memory accumulation during long sessions, and improve the game interface.

It does not provide unlimited resources, generate Latinum, manipulate event points, or guarantee top positions in events.

**Press F8 while the game is running to open or close the mod settings menu.**

---

# Included plugins

## STFC.ConfigManager

A central in-game menu for managing the installed plugins and their settings.

Press **F8** while the game is running to open or close the menu. ConfigManager provides English and Russian menu labels and supported live enable and disable controls.

## STFC.Miner

Adds a mining button to the fleet interface. It finds an available mining node, sends the selected ship to it, and continues working after the node is depleted.

Miner supports full or protected cargo limits, automatic recall to the starbase, and an optional return to the mining system after unloading.

## STFC.Repair

Automatically repairs damaged or destroyed ships after they return home. It can also repair defensive platforms, request alliance help, and use available repair speedups and repair tokens.

**Latinum is never used for repair speedups.**

## STFC.AntiSpam

Automatically blocks advertising pop-ups without affecting the shop, rewards, confirmations, or other in-game windows.

It can be enabled or disabled at any time.

## STFC.MemoryInspector

Performs lightweight scheduled memory cleanup during long game sessions.

The cleanup interval can be set to **5, 10, 15, 20, 25, or 30 minutes**. A manual cleanup key can also be assigned.

## STFC.Transformers

Improves interface usability by enlarging the speedup selection, combat report, and ship statistics windows.

It can also change the scale of object information windows and keep ship names and alliance tags visible at different zoom levels.

## STFC.CommunityPatch

Provides a safe set of interface improvements, including configurable UI scale, extended zoom inside star systems, and shop offer preview during an active cooldown timer.

Not every Star Trek Fleet Command update requires downloading new plugin versions.

In most cases, the game and the modification pack continue working without changes. Sometimes an update may affect only one plugin or one specific function.

We monitor game updates and try to release required fixes as quickly as possible.

# Installation and first launch

1. Close Star Trek Fleet Command completely.
2. If you already use BepInEx or other plugins, create a backup of the existing BepInEx folder.
3. Download the latest release from this GitHub repository.
4. Extract the archive into the **Star Trek Fleet Command installation directory**.
5. Launch the game and wait for BepInEx to initialize.
6. Log into your game account.
7. Press **F8** to open the mod settings menu.
8. Select a plugin and configure the required options.
9. Press **F8** again to close the menu.

The first game launch may take slightly longer while BepInEx initializes.

If the menu does not appear immediately, wait until the game has fully loaded and then press **F8** again.

## Included plugins

### STFC.Armada

Automates consecutive armada launches for the selected ship. It finds the nearest available armada of a configured rarity, checks launch-token availability, creates the armada, sends the ship into the circle, and can optionally use an instant-start speedup. After completion, it searches for the next target.

### STFC.Berserker

Provides automated hostile and marauder grinding for the selected ship. It targets the nearest suitable enemies using configurable level and ship-class filters, applies adjustable delays between attacks, and tracks kills. It can stop or recall the ship when cargo is full, hull health is low, the system changes, or the kill limit is reached.

### STFC.GS31

Automates the GS-31 ship’s ChainShot ability. It prioritizes beam-marked hostiles, builds a chain of up to five targets, and activates the ability whenever its cooldown is ready. The task can be limited by kill count or runtime, after which the ship is automatically recalled.

### STFC.Hound

Enhances the game’s reconnaissance interface. It marks ships carrying over-protected cargo (OPC), displays cloaked ships without making them attackable, and shows the remaining starbase shield time.

To locate a player, open their profile and click the house icon in the bottom-right corner. Hound will show the system where the player’s base is located and the remaining shield duration if a shield is active.

### STFC.ConfigManager

Central in-game settings menu. Press **F8** to open it. Includes English and Russian interfaces.

### STFC.Miner

Finds available mining nodes, continues after depletion, monitors cargo, and can recall or return the ship automatically.

### STFC.Repair

Automatically starts supported repairs, requests alliance help, and can use available repair speedups. It does **not** spend Latinum.

### STFC.MemoryInspector

Periodic memory cleanup with configurable **5–30 minute intervals** and a manual cleanup hotkey.

### STFC.Transformers

Enlarges windows, improves combat reports, statistics, and the object viewer, and can display ship names and alliance tags at different zoom levels.

### STFC.CommunityPatch

Includes interface scaling, extended camera zoom, and shop cooldown preview.

### STFC.AntiSpam

Automatically blocks advertising pop-ups without affecting the shop, rewards, confirmations, or other in-game windows. It can be enabled or disabled at any time.
